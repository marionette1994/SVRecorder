# SV戦績オート（SVRecorder）

Shadowverse: Worlds Beyond の対戦を画面から自動で読み取り、[SV戦績トラッカー（SVT）](https://github.com/marionette1994/SVT) に取り込めるCSVを作る Android アプリです。

## 仕組み

- 画面キャプチャ（MediaProjection）を0.7秒ごとに取得し、端末内の日本語OCR（ML Kit）と画像照合で判定します。通信はしません。
- **対戦開始（VS）画面**：左右カードの「先攻／後攻」の字を画像照合して先後を判定します。クラスはアイコン照合と、クラス名の文字（「ネメ」「ヤル」などの断片でも可）から判定します。相手の名前も読み取ります。
- **リザルト画面**：上部の「WIN」は勝ち、「RESULT」は負けです。文字が読めないときは、上部の明るさ（勝ちは金色に光る）で判定します。
- クラスアイコンは最初はネメシスとロイヤルだけ覚えています。それ以外のクラスは、文字で読めたときや手で直したときに覚えます。
- 縦画面のときは解析を止めて、電池を節約します。

## インストール

1. スマホで Releases の最新版を開き、`SVRecorder.apk` をダウンロードします。
   - 直リンク：`https://github.com/marionette1994/SVRecorder/releases/latest/download/SVRecorder.apk`
2. 「提供元不明のアプリ」のインストールを、ブラウザに許可します。
3. 更新するときも、同じ手順で上書きインストールできます（毎回同じ鍵で署名しています）。

## 使い方

1. アプリを開き、「設定」にSVTと同じ**シリーズ名**と**デッキ名**を入れます。
2. 「記録を開始」を押し、画面の記録を許可します（Android 14以降は「1つのアプリ」でシャドバだけを選んでもかまいません）。
3. シャドバで対戦します。記録されると通知に結果が出ます。
4. 終わったらアプリで ⚠要確認 の記録を直し、「CSVを保存」を押します。
5. SVT の 設定 → CSV取り込み →「追加」で、保存したCSVを選びます（重複は自動でスキップされます）。

## うまく読めないとき

アプリ下部の「診断」に、直近のフレームで何を読み取ったかが出ます。先後の照合スコア、アイコンの判定、明るさなどです。誤判定したときは、その内容とスクショを添えて相談してください。

## ビルド

`main` に push すると GitHub Actions が APK をビルドし、Release に添付します。署名鍵（`app/signing.keystore`）は個人用アプリなのでリポジトリに含めています。
